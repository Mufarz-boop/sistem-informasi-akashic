Information that belongs where you are.

Akashic connects location, regional context, and information into one web-based experience.

ABOUT AKASHIC

A different way to experience information.

Akashic is not just a news website or an information catalogue. It starts from the idea that information has geographic context.

Information about a place is more relevant to someone who is actually in that place. With the visitor's permission, Akashic uses the browser Geolocation API to get latitude, longitude, and accuracy. The Location Engine and Region Engine then match that position to geographic polygons and the regional hierarchy.

THE CORE IDEA

Where. What. When.

WHERE

Location determines the regional context. Akashic uses the visitor's position, with permission, to work out which region information should come from.

WHAT

Information, events, and news create the content layer. Three kinds of content are brought together in one place.

WHEN

Time determines relevance. Content can carry a publication time, an event start and end, and a status.

How Akashic Works

From your location to information that matters.

  1. 01

    Locate

    The browser asks for permission, then provides:

    • latitude
    • longitude
    • accuracy

    Location is used only after the visitor allows it.

  2. 02

    Identify Region

    The Location Engine passes coordinates to the Region Engine, which finds the region using geographic polygons and the regional hierarchy.

  3. 03

    Understand

    The region is connected with:

    • Information
    • Events
    • External News
  4. 04

    Filter & Organize

    The Feed Engine combines content by:

    • region
    • category
    • publication time
    • event time
    • relevance
  5. 05

    Deliver

    Content appears through:

    • public feed
    • information page
    • event content
    • regional news
    • web push
REGION INTELLIGENCE

Built around regions, not assumptions.

Akashic organizes places as a hierarchy, from country down to district.

  • COUNTRYIndonesia
    • PROVINCEAceh
      • CITY / REGENCYKota Langsa
        • DISTRICTLangsa Kota

Akashic does not simply calculate distance from a point. Regions are represented using geographic boundaries so that location context follows actual administrative or defined geographic areas.

This is what the Polygon-based Region Engine does: it checks which boundary a position falls inside, the way a map shows which district you are standing in.

TRACKING HISTORY
  • Reading information needs no public account or login.
  • Geolocation is used only when you give permission.
  • Latitude and longitude serve as context to find your region.
  • Akashic is not designed to track movement or keep location history as tracking history.
  • A browser push subscription is not a personal identity.
  • You can refuse location permission. Akashic still works, with more general regional information.

What if you don't share your location?

Akashic still works. It never forces you to share.

PUBLIC AND ADMIN

One system, two experiences.

PUBLIC

For visitors.

  • browse information
  • discover events
  • read regional news
  • use location context
  • receive notifications

Needs no login, registration, or account creation.

ADMIN

For managers of the system.

  • manage regions and categories
  • manage information and events
  • review news
  • manage notification content
  • monitor system activity

Uses authentication that is separate from the public experience.

DESIGN PHILOSOPHY

Information should meet people where it matters.

Place.Context.Relevance.

Akashic is built around a simple idea: information becomes more meaningful when it is connected to context. Place says where, time says when, and relevance decides what reaches you.
